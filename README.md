# 📝 React + Supabase Notes App

A simple note-taking web application built as a personal learning project to explore **React** and **Supabase**. 

> **Note:** This repository is a sandbox project created to learn the basics of state management in React, integration with backend services, and handling authentication using Supabase.

---

## 🚀 Features

- **User Authentication:** Sign up and sign in using Supabase Auth.
- **CRUD Operations:**
  - ➕ Create new notes with titles and content.
  - 👁️ View a list of existing notes ordered by creation date.
  - ✏️ Edit existing notes.
  - 🗑️ Delete notes.
- **Data Security:** Row Level Security (RLS) enabled so users can only view and manage their own notes.

---

## 🛠️ Tech Stack

- **Frontend:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL + Auth)
- **Language:** JavaScript (ES6+)

---

## 📋 Database Schema

The app uses a single table named `notes` configured in PostgreSQL via Supabase:

```sql
create table public.notes (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  title character varying null,
  content text null,
  user_id uuid null,
  constraint notes_pkey primary key (id),
  constraint notes_user_id_fkey foreign KEY (user_id) references auth.users (id)
) TABLESPACE pg_default;
```

## ⚙️ Local Setup & Run

### Prerequisites
- [Node.js](https://nodejs.org/) installed on your machine.
- A [Supabase](https://supabase.com/) account and project.

### Step 1: Clone the Repository
```bash
git clone https://github.com/your-username/your-repo-name.git
cd your-repo-name
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Configure Environment Variables
Create a `.env.local` file in the root directory and add your Supabase credentials:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### Step 4: Run the Application
```bash
npm run dev
```

Open your browser and navigate to the local server URL provided by Vite (usually `http://localhost:5173`).
